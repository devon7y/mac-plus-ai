Help

Using this page
  • Ctrl is the Mac's ⌘ key: Ctrl Q quits a program.
  • Games quit with Esc (or ` when full screen or the locked mouse takes Esc).
  • Blockworld: click the screen to capture the mouse for looking around. Esc gives the mouse back and opens the game's menu; Esc again returns to the game, then click to capture again. ` opens the menu without letting go of the mouse.
  • Fast runs the Mac about four times faster than a real Plus; Glider, and typing in Pixel, Dream and Doodle, run at real speed.
  • Sound comes on with your first click or key press; the sliders below set the hardware and software volumes, and the browser tab's mute silences both.
  • Drag around the Mac to look; scroll or pinch to zoom. You can type on the 3D keyboard and click the 3D mouse.
  • Nothing is kept: reloading the page starts the Mac afresh.

Insert Disk

Drop a disk image, or a .sit / .sea / .hqx / .bin / .zip download: the page unpacks it and puts it on a disk, which appears on the Mac's desktop. Double-click the app on it. Your files stay in your browser: nothing is uploaded. To eject, drag the disk to the Trash (or File > Eject).

or drop it anywhere on the page. Tip: click the floppy slot on the Mac to open the file picker directly.

On the Mac now

    Download a disk to keep what the app saved on it; insert it again next time. A restart ejects the disks; Re-insert puts one back.

    Make your own app with an AI

    Paste this into your AI assistant, then insert the .dsk file it builds:

    Write a classic Macintosh application in C for a Macintosh Plus running System 6: a 68000 CPU (no 68020 or FPU instructions), 4 MB of RAM and a 512×342 black-and-white screen. Use only the original Toolbox (QuickDraw, Window, Menu, Event and Dialog Managers): no Color QuickDraw and no System 7 calls. Build it with Retro68 (https://github.com/autc04/Retro68); its build writes a floppy disk image, <App>.dsk. Put any files the app needs on that same disk. Give it a File menu with Quit (Command-Q), and if it is a game played with the keyboard, also quit (or go back to its title) on Esc and on ` (backquote). Give me the .dsk file.

    Classic games and apps

    • Macintosh Garden and Macintosh Repository have thousands; Glider and the Talking Moose on this Mac came from there.
    • Pick black-and-white titles that run on System 6 and a Mac Plus.
    • Disk images and StuffIt, BinHex, MacBinary and .zip downloads all work; StuffIt X (.sitx) and Compact Pro (.cpt) need unpacking first, for example with The Unarchiver.
    • Respect each title's licence.
